# 方块碰碰场 · Block Bounce

可直接部署到 GitHub Pages 的纯静态小游戏。方块在场地中自动弹跳，碰到边界、伙伴或障碍物时会反弹，但不会受玩家手动操控。它们会自动拾取一次性道具；AI 会优先攻击曾对自己造成碰撞或伤害、敌意最高的对手，并预测移动轨迹（包含竞技场边界反弹）来发射武器。没有人工瞄准或操作按键。

## 已实现

- 浅色玻璃拟态 UI；手机端优先布局，设置控件有更大的触控区域，页面不需要横向滚动；大屏桌面会扩展竞技场宽度和高度。
- 方块数量可设为 1–48，每个方块初始血量默认 **1000 HP**。当前 UI 暂定血量范围为 1–10000 HP，可根据你希望的范围再调整。
- 五种地图：
  - **空白竞技场**：默认地图，没有障碍物或环境伤害。
  - **森林**：树木（100 HP）和石头（1000 HP）是可被撞坏的实体障碍。
  - **沙漠**：仙人掌（100 HP）是可被撞坏的实体障碍；接触时每个方块每秒最多损失 2 HP。
  - **冰原**：整片冰面，摩擦很低，方块会明显滑行；不生成障碍物。
  - **核辐射区**：树木障碍和当前暂定的 5 个固定位置荧光辐射坑。方块进入坑内后移速减半；每在坑内持续 1 秒损失 2 HP，离开后减速和计时恢复。辐射坑的具体分布可再调整。
- 森林、沙漠和核辐射区可配置 0–12 个障碍，切换时默认 4 个；空白竞技场和冰原始终没有障碍。
- 障碍耐久通过自动碰撞降低：当前暂定按 `round(撞击方向速度 ÷ 场地格尺寸 × 10)` 计算伤害，至少 1 点。耐久归零后障碍消失；树木和仙人掌较容易撞倒，石头更耐撞。具体公式或系数尚可调整。
- 可开关“碰撞导致加速”。关闭时碰撞反弹仍正常，只是不因碰撞增加速度。
- 方块血量会显示在角色列表中，受伤后竞技场方块下方也显示血条；血量归零会淘汰该方块，其他方块继续比赛，直到全员淘汰。
- **道具总数最多 2 件**，计算场上拾取物与方块手持道具；一局开始时随机生成 2 件，有空位时每 6 秒最多补充 1 件。拾取自动触发，远程武器可用时会立即发射；全局使用冷却 **6 秒**，冷却期间捡到的道具会留在手上等待使用，期间仍计入总数。方块淘汰时会掉落手持道具。
  - **刀**：持有者与另一方块碰撞时一次性造成 5 HP。
  - **手枪**：自动向 AI 选中的目标预测射击，子弹速度中等，命中造成 10 HP。
  - **霰弹枪**：中速散射 3 发，每发命中造成 10 HP。
  - **狙击枪**：极快子弹，命中造成 20 HP。
  - **喷火器**：朝目标喷射 5 秒，火焰扇形范围内每秒造成 2 HP。
  - **C4**：持有者碰到对手后安装到对手身上，5 秒后爆炸；半径 2 格内造成 20 HP，安装者免疫爆炸伤害。
- 枪弹、喷火和 C4 爆炸不会伤到使用者/安装者。武器命中等攻击行为会提高对手对攻击者的敌意分数；没有敌意记录时，AI 先选最近目标。AI 会预测目标速度以及撞墙后的反弹轨迹。
- 每局随机生成不重复颜色；方块有不同的待机表情，碰撞或受伤时会变化。
- 暂停、重新开始、碰撞计数、存活数和最近碰撞事件。

## 游戏配置接口

浏览器控制台可使用 `window.BlockBounce`：

```js
BlockBounce.startMatch({
  blockCount: 12,
  blockHealth: 1500,
  mapType: 'forest', // empty | forest | desert | ice | nuclear
  obstacleCount: 6, // 空白竞技场和冰原会强制为 0
  collisionAcceleration: true,
});

BlockBounce.getConfig();
BlockBounce.getSnapshot(); // 包含血量、手持道具、道具冷却与命中计数
BlockBounce.createUniqueColors(12); // 返回本局互不重复的颜色
BlockBounce.systems.items.enabled; // true
BlockBounce.systems.items.getCurrent(); // 场上拾取物、手持物与冷却状态
```

默认配置包括 8 个方块、每个 1000 HP、空白地图、0 个障碍物、关闭的碰撞加速以及启用道具。森林、沙漠和核辐射区在未指定障碍物数量时使用默认值 4。数量范围见 `BlockBounce.limits`；道具规则见 `BlockBounce.itemRules`；障碍物创建接口位于 `BlockBounce.systems.obstacles`。地图不支持障碍时，该接口返回空数组。

## 本地运行

无需安装依赖。直接打开 `index.html`，或在仓库根目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## GitHub Pages

文件位于仓库根目录。合并到 `main` 后，打开 **Settings → Pages**，选择 **Deploy from a branch**，分支选择 `main`、目录选择 `/(root)` 并保存即可。
