# 方块竞技场 · Block Arena

一个可直接部署到 GitHub Pages 的静态小游戏原型：四种颜色的方块在带网格和硬边界的竞技场中移动、碰撞并自动发射弹丸。

## 当前原型包含

- 蓝、绿、红、黄四名方块角色；角色以方块脸和小型炮管绘制，无外部图片或依赖。
- 蓝色角色由玩家控制，其他角色会在场地内移动并自动瞄准射击。
- 竞技场边界、玩家之间的实体碰撞、弹丸与角色碰撞、生命值与淘汰状态。
- 桌面端使用更大的地图；窄屏手机使用精简地图，并提供触屏方向键和滑动操作。
- 暂停、继续、重新开局。所有资源均为本地 HTML、CSS、JavaScript 和 Canvas。

## 本地运行

无需安装依赖。可以直接打开 `index.html`，或在仓库根目录运行：

```bash
python3 -m http.server 8000
```

随后访问 `http://localhost:8000`。

## 发布到 GitHub Pages

仓库文件位于根目录，合并到 `main` 后，在 GitHub 仓库中打开 **Settings → Pages**，选择 **Deploy from a branch**，分支选择 `main`、目录选择 `/(root)` 并保存即可。GitHub Pages 会从根目录的 `index.html` 发布。

## 后续可扩展

目前重点是基础竞技场、方块角色和碰撞逻辑；后续可以继续加入角色自定义、更多地图障碍、武器、音效、关卡或联机玩法。
